HTTP 🔓vs HTTPS 🔐

What is HTTP🔓?

HTTP stands for HyperText Transfer Protocol. It is used for communication between a client and a server.

  • Port: 80
  • No TLS encryption
  • Less secure
  • URL starts with http://

What is HTTPS 🔐?

HTTPS stands for HyperText Transfer Protocol Secure. HTTPS is HTTP communication protected using TLS.

  • Port: 443
  • Uses TLS
  • Encrypts data in transit
  • More secure
  • URL starts with https://

HTTP vs HTTPS

Feature HTTP HTTPS
Security Less secure 🔓 More secure 🔐
Encryption No TLS Uses TLS
Port 80 443
URL 🔓http://github.com://github.com 🔐https://github.com//github.com
Certificate Not required TLS certificate

What is TLS🚀?

TLS stands for Transport Layer Security. It protects data while it travels between the client and server.

TLS provides:

  1. Encryption
  2. Authentication
  3. Data integrity

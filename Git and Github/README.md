# 🎲 HTTP vs HTTPS

## 🚀 Introduction

This project explains the difference between HTTP and HTTPS.

## HTTP 🔓

HTTP stands for HyperText Transfer Protocol.

- Uses port 80
- No TLS encryption
- Less secure
- URL starts with `http://github.com`

## HTTPS 🔐

HTTPS stands for HyperText Transfer Protocol Secure.

- Uses port 443
- Uses TLS encryption
- More secure
- URL starts with `https://github.com`

## HTTP🔓 vs HTTPS 🔐

| Feature | HTTP | HTTPS |
|---|---|---|
| Security | Less secure | More secure |
| Encryption | No | Yes |
| Port | 80 | 443 |
| Protocol | HTTP | HTTP + TLS |
